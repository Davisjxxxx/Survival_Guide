# Recommended model allocation

Use the active tool-capable Codex model for routine repository tasks, a deeper reasoning pass for ambiguous evidence or architecture, and qualified reviewers for clinical, taxonomic, engineering and regulatory decisions. One model may draft or check a decision. Independent specialist approval requires a separate reviewer with recorded qualification and an evidence receipt.

| Sprint | Lead model | Independent review or approval |
|---|---|---|
| S00 | GPT-6.2 Sol for inventories, hashes and Git | GPT-6.2 Astra for contradictory evidence and custody exceptions |
| S01 | GPT-6.2 Astra for schema and fail-closed gates, Sol for test and archive handling | Separate technical review, then owner Gate A decision |
| S02 | GPT-6.2 Astra for claims, limits and primary-source synthesis, Sol for register integrity | Subject reviewer for high-consequence claims |
| S03 | GPT-6.2 Sol for card implementation and render checks, Astra for failure analysis | Independent technical editor and field reviewers |
| S04 | GPT-6.2 Astra for reconstruction and error modes, Sol for design/build | Navigation, rescue and winter specialists |
| S05 | GPT-6.2 Astra for clinical source comparison, Sol for assembly | Wilderness-medicine clinician |
| S06 | GPT-6.2 Sol for asset provenance and atlas records, Astra for comparison structure | Botanist and rights reviewer |
| S07 | GPT-6.2 Sol for repetitive profile packaging, Astra for difficult comparisons | Botanical specialist |
| S08 | GPT-6.2 Astra for evidence triage | Mycologist |
| S09 | GPT-6.2 Astra for legal/context conflicts, Sol for citation and asset QA | Local regulations and geology reviewers |
| S10 | GPT-6.2 Astra for scenario and failure-mode review, Sol for worksheet and render | Emergency-management and qualified trade reviewers |
| S11 | GPT-6.2 Astra for evidence and conditions, Sol for structured production | Food-safety specialist and Extension reviewer |
| S12 | GPT-6.2 Astra for environmental limits, Sol for cross-references | Environment-specific technical reviewers |
| S13 | GPT-6.2 Sol for indexing and build verification, Astra for coverage conflicts | Independent editorial audit |
| S14 | GPT-6.2 Astra for reviewing issue evidence, Sol for tracking retests | Qualified humans own all sign-offs |
| S15 | GPT-6.2 Sol for reproducible packaging and checks, Astra for discrepancy review | Technical/rights acceptance and publication decision by owner |

Escalate to Astra when evidence sources conflict, an engineering decision can invalidate whole sections, or a high-consequence claim has unresolved applicability. Keep routine verification reproducible in scripts and attach receipts to the relevant decision.
