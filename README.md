# Survival Guide / Survival Field Encyclopedia

An offline-first, Minnesota-focused illustrated survival-reference project.

## Authoritative working rule
**Every substantive project artifact must be committed to this GitHub repository.** ChatGPT download links, generated archives, and local working folders are temporary outputs, not the sole system of record.

Save research notes, source/claim ledgers, manuscripts, editable original diagrams, build scripts, validation checks, compiled reader previews, and release packages in versioned, reviewable paths. Preserve existing material; use review branches and pull requests for significant changes. Verify a successful GitHub commit and the files' contents before marking work retained.

## Research / publication boundary
Draft field guidance is **not** a substitute for local official warnings, professional rescue training, medical judgment, or conditions-based decisions. Synthetic scenes are illustrations, not verified field photographs. Require source checks, qualified safety review, visual inspection, and explicit release approval before representing material as field-tested or publishing.
